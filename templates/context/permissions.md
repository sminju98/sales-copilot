## 권한 모드 (`approval_mode` — 5종 중 1개, SET-12)
- [ ] **AUTO** — 허용범위 안 자동 실행
- [ ] **BATCH** — 하루/캠페인 단위 묶음 승인
- [ ] **PER-ITEM** — 발송·일정·제안 건별 승인
- [ ] **DRAFT ONLY** — 조사·초안까지만 (미설정 시 기본 — 자동 발송 절대 금지)
- [ ] **ESCALATE** — 권한 밖은 전부 상신

## 상신[E] 기준 (`escalate_rules` — SET-12, 예시를 내 기준으로 교체)

- 할인율 (예: 10%) 초과 · 계약조건 변경 → DEAL-05, DEAL-11
- 대기업·투자사·전략 파트너 접촉 → OPP-13, INB-12
- 부정적 이슈·클레임 발생 → 즉시
