# 기본 5터치 시퀀스 — {세그먼트/캠페인 이름}

**타깃**: {ICP 세그먼트 한 줄} · **발신**: {발신자·계정} (SET-11) · **채널**: {이메일 기본 + 대체 채널}
**목표**: 회신 → 콜 제안. 완벽한 개인화보다 충분한 관련성 — 팩트 오류 없고 관련성 있으면 70% 완성도에서 보낸다.

## 1일차 — 첫 연락: 핵심 문제를 짚는다 (OUT-05~07)
- **목적**: "우리를 알아보고 연락했다"는 관련성 증명 + 부담 낮은 첫 반응 얻기
- **각도**: 상대 회사의 {확인된 사실: 최근 투자/채용/출시/공개 자료} → 그로 인해 생겼을 {문제 가설(추론임을 표시)} → 우리가 도운 방식 한 줄
- **골격**:
  ```
  제목: {회사명}의 {문제 키워드}, {우리 상품 카테고리} 관련 제안
  {이름}님, {발신자·소속}입니다.
  {회사명}이(가) {확인된 사실 — 출처 있는 것만} 하신 걸 보고 연락드립니다.
  이 시기엔 {문제 가설}가 과제일 것으로 보입니다. (단정 금지)
  저희는 {유사 고객·상황}에서 {한 줄 가치제안}을 해왔습니다.
  {부담 낮은 CTA: 예) 간단히 자료 하나 보내드려도 될까요? / 15분 통화 가능하실까요?}
  {서명 · 발신자와 목적 명확히 · 수신거부 안내}
  ```

## 3일차 — 짧은 후속: 다른 근거 하나 (OUT-08)
- **목적**: 첫 메일을 위로 끌어올리기. 재촉이 아니라 근거 추가
- **각도**: 첫 메일과 **다른** 근거 1개({다른 사실 또는 다른 효용}) + 한 문단 이내
- **골격**: "지난 메일에 덧붙여 — {회사명} 같은 {세그먼트}에서는 {추가 근거 한 줄}. {같은 CTA 반복}"

## 6일차 — 주는 터치: 사례·정보·도움 (OUT-08)
- **목적**: 요구 없이 먼저 준다. 답장 안 해도 남는 가치
- **각도**: {실제 고객 사례(수치는 확인된 것만) / 관련 자료·벤치마크 / 무료로 해줄 수 있는 것}
- **골격**: "{유사 회사}가 {확인된 결과}를 낸 사례를 공유드립니다. {회사명} 상황에 맞을지는 {조건}에 달려 있는데, 원하시면 {구체적 도움}을 먼저 해드리겠습니다."

## 10일차 — 채널 전환: 전화 또는 다른 경로 (OUT-09·OUT-18)
- **목적**: 이메일이 안 닿는 경우를 배제. 사람 또는 채널을 바꾼다
- **각도**: {전화 시도 / 소개 경로: {소개자}에게 소개 요청 / "제가 잘못 짚었다면 {업무} 담당자를 알려주실 수 있을까요?"}
- **주의**: 전화·문자는 채널별 규칙이 다르다 → [[send-policy]] 통과 후

## 15일차 — 마지막 확인: 정중한 클로징 (OUT-19)
- **목적**: 열린 고리를 닫고, 장기 재접촉 조건을 남긴다
- **각도**: 압박 없는 마무리 + 문 열어두기
- **골격**: "여러 번 연락드려 죄송합니다. 지금은 시점이 아닌 것으로 알고 정리하겠습니다. {재접촉 명분: 예) {상황} 생기시면} 편하게 찾아주세요."
- **이후**: 시퀀스 종료 → `next_action = {N개월 후 또는 새 구매 신호 시} 재접촉`으로 저장(무응답은 거절이 아니다 → [[revive]])

## 중단 조건 — 해당 즉시 시퀀스 전체 중단 + suppressions 반영 (OUT-20)
명시적 수신거부 / 명확한 거절·재접촉 금지 / 반송·잘못된 연락처 / 사실상 무관한 대상으로 판명 / 최대 접촉횟수 도달(기본 5회) / 법·채널 정책상 발송 불가.
**회신·미팅 확정 시에도 시퀀스는 중단** — 이후는 [[classify-reply]]·[[book-call]]로 넘어간다.
