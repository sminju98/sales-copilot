# 01 — 입력 3개 정규화 (캠페인 인테이크)

<!-- 원본: salesfactory-plugin skills/salesfactory/references/01-intake.md — sales-copilot 통합판 -->

캠페인에 필요한 입력은 딱 3개. 이걸 **1회 정규화해 영업 컨텍스트에 저장**하고 이후 재사용한다 — 매번 다시 묻지 마라(이미 있으면 이 단계 통째로 건너뛴다). 저장 위치: 제품 정체 → `context/products.md`의 "콜드메일 소구" 절, 톤·발신자 → `context/message-style.md` + config `me`.

## 입력 1 — 타겟군 (누구에게)

평문으로 받는다. 예: "서울 강남 성형외과", "월매출 10억 이상 화장품 브랜드", "미국 SaaS 스타트업 마케팅 담당".

정규화 → **ICP(Ideal Customer Profile)** 구조로 (`context/icp.md`와 정합 — 이미 [[icp]]가 확정한 세그먼트가 있으면 그걸 쓴다):
```
{
  industry:   업종 (필수)
  geo:        지역/국가 (필수 — 이게 국내/해외 트랙을 가른다, 02 참조)
  size:       규모 신호 (직원수·매출·투자단계, 있으면)
  role:       접촉할 직책 (대표·마케팅·구매 등, 있으면)
  signals:    타이밍 신호 (채용중·신제품·투자유치 등, 있으면)
}
```
- geo가 모호하면 **반드시 물어라**("국내 기업인가요, 해외인가요?"). 국내/해외는 발송 법제가 다르다(08) — 법제 분기라서 예외적으로 질문이 허용되는 항목이다.
- 사용자가 "타겟이 불법이어도 내 알 바 아니다"라고 해도, **도구의 데이터 수집 경로는 합법 소스만**(02). 타겟 선택은 사용자 책임, 수집 방법은 우리 책임.

## 입력 2 — 회사 자료 (무엇을 파는가)

URL / 파일 / 줄글 중 아무거나. URL이면 웹으로 읽어 `03-page-reading.md` 절차로 소구 재료를 뽑는다.

→ `context/products.md`에 이 블록(product_context)으로 저장:
```
company:      회사명
what:         무엇을 파는가 (한 줄)
sellingPoints: 발굴한 소구 전량 (04의 우선순위대로, 원문 인용)
offer:        오퍼 (할인·무료체험·보장 등, 있으면)
proof:        증거 (수치·고객사·수상·리뷰, 있으면 — 없으면 지어내지 마라)
targetPain:   타겟이 겪는 문제 (사용자 설명 + 추론 — 추론은 추론으로 표기)
cta:          목표 행동 (미팅·데모·회신·가입)
```

## 입력 3 — 영업 내용 (어떻게 말할까)

"어떤 걸 강조하고 싶은지, 어떤 느낌으로 보낼지". → `context/message-style.md` + config에 저장(voice):
```
sender:       발신자 실명·직책 (실존 인물. 없는 사람 지어내기 금지 — 신뢰·AUP)
              → config me.name·me.send_as·me.sender_email
tone:         정중 / 친근 / 직설 (사용자 선택, 기본 정중 — 고객향 문면은 절제가 기본)
emphasis:     사용자가 강조하고 싶은 소구
language:     ko / en (타겟 geo 기반, 05에서 확정)
signature:    발신자 서명 블록 (회사명·전화·주소) → config me.signature
```

## 즉석 피드백 (신뢰 신호)

입력 3개를 받은 직후 **제품 요약 카드 + ICP 초안 + 샘플 메일 1통**을 묻지 말고 즉석에서 만들어 보여줘라. "작동한다"는 감을 첫 대화에서 준다. 실제 발굴·적재는 그 다음.

## 필수 입력 게이트 (국내 트랙이면)

국내 발송은 08의 '영업 메일 판정'을 따른다. 어느 트랙이든 **발신자 실명·소속·연락처(판정 조건 ③ 투명성)는 필수** — signature에 회사명·전화번호·주소 3개가 다 있어야 한다. 광고성 정보로 판정·전환되는 문면이면 이 3개 + 무료 수신거부 수단이 **법정 표시의무**가 된다(08). 하나라도 비면 적재 단계에서 막고 사용자에게 채우라고 요구한다.
