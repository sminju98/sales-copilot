## 대원칙 2개

1. **타겟 선택은 사용자, 수집 경로는 우리.** 사용자가 어떤 타겟군을 넣든, 우리는 **합법 소스로만** 조사한다.
2. **수신자 소재지가 법제를 가른다.** ICP.geo로 트랙을 강제 분기한다. 이건 선택이 아니라 파이프라인 자체가 달라진다.

## 리드 풀 점검 먼저

발굴 전에 `crm.py stats`·명함·기존 시트로 보유 리드부터 확인한다. **이번 주 목표 접촉 수에 못 미치면** 웹 발굴만으로 채우지 말고 Apollo 같은 B2B 리드 DB 구매·구독을 권유한다 — 상세 절차·CSV 임포트·커넥터 경로는 [[find-leads]].

## 2단 발견 (이미지팩토리 brief-extractor의 발견 논리 차용)

한 번에 정밀 조사하지 말고 2단으로:
- **1단 (판 파악)**: ICP로 웹을 넓게 검색해 "이 판에 어떤 회사들이 있는지" 후보 리스트를 만든다. 값싸게.
- **2단 (정밀 조사)**: 후보 각각을 도메인·공개페이지로 좁혀 실재·적합·연락 가능성을 확인한다(04로 연결).

## 트랙 A — 해외 (opt-out 법제): 풀 발굴

파이프라인: ICP → 웹검색으로 회사·담당자·근거 발굴 → **공개 페이지에 문자 그대로 있는 이메일만** 수집(추측 금지) → 검증(있으면) → `contacts` 시트에 `sourceUrl`·`matchedSnippet`과 함께 적재.

- 역할 계정(info@, contact@, sales@ 등) 우선 — 개인정보성이 낮아 안전.
- 자연인 실명 주소(firstname.lastname@)는 일부 국가(독일·이탈리아 등)에서 B2B도 사전동의 필요 → 보수적으로 role 계정 위주.
- 무료 웹메일(gmail.com, outlook.com 등)로 온 담당자는 개인 주소일 확률이 높아 제외.

## 트랙 B — 국내: '영업 메일 판정'으로 발송 여부가 갈린다 (08)

국내 사전동의 규제(정보통신망법 제50조)의 대상은 '영리목적 **광고성** 정보'다. **특정 회사의 특정 문제를 짚은 1:1 개별 거래·제휴 제안은 광고성 정보로 단정되지 않는다** — 그래서 국내 트랙은 무조건 차단이 아니라 **판정**이다:

- **발송 가능 경로 (기본)**: 08의 판정 조건 5개(1:1 개별 작성 / 거래 제안 본질 / 발신자·목적 투명 / 정중한 종료 수단 / 빈도 상한)를 전부 충족하는 개별 영업 제안 → `legalBasis=SALES_PROPOSAL_1TO1`로 적재하면 발송 게이트를 통과한다. 판정이 애매하면 **문면을 고쳐서 판정에 맞추는 게 기본 동작**(발송 포기가 아니라 문면 수정).
- **광고성으로 넘어가면**: 동일 문면 대량 살포·할인/프로모션 소구가 주가 되는 순간 광고성 정보 → (광고) 표기 + 사전 동의 경로(옵트인 리스트·거래관계 6개월 예외, 08)로 분기하거나 전화([[phone-call]])·소개 경로로 전환.
- **국내 후보는 이메일과 함께 대표번호·공개 문의폼 URL도 수집**한다(03). 이메일이 공개돼 있지 않거나 판정을 못 넘기는 후보는 문의폼·전화·소개가 접촉 경로다 — 이때는 회사명·업종·규모·근거(뉴스·채용시그널)를 담은 **타겟 리서치 리포트**로 사용자에게 넘긴다.
- 거래관계 예외(6개월 내 직접 거래 + 동종 재화)는 **광고성 정보를 보낼 때의** 동의 대체 경로다(08). 공개출처 발굴 주소는 이 예외에 안 든다.

## 합법 소스 (전 트랙)

허용:
- LLM 웹검색(공개 웹 조사) · 공식 오픈API(네이버 검색, 사람인 등 승인제) · 공공데이터(국세청 사업자상태·LOCALDATA 인허가·DART) · 공개 회사 페이지의 명시된 연락처.

금지:
- **크롤링**(로그인 뒤 데이터·이용약관 금지 명시·기술적 차단 우회) — 잡코리아 v 사람인 DB제작자권 4.5억 배상 판례.
- **이메일 주소 패턴 추측 생성** — 형사(제50조 제5항 제2호). 자동 수집 프로그램도 금지(제50조의2).
- 타 서비스 DB 상당부분 복제.

## 게이트 기준 ("애매하면 제외")

후보를 발송 대상에 넣기 전 통과해야 할 것:
- [ ] ICP에 실제로 맞는가 (업종·규모·지역) — 인접하거나 애매하면 제외
- [ ] 연락 수단이 **공개 출처에 실재**하는가 (`sourceUrl` 있음)
- [ ] 트랙 B면: 08 판정 통과(SALES_PROPOSAL_1TO1) 또는 동의 경로 증빙이 있는가 — 아니면 리포트·문의폼·전화 대상
- [ ] suppression·중복(이미 보낸 상대) 아닌가 — `state.py check` + 로컬 `crm.py suppress-check`로 확인

정확도가 볼륨보다 중요하다. 스팸함 가는 300건보다 인박스 꽂히는 30건이 답장을 더 받는다.
