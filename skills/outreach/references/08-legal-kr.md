## 출발점 — 규제 대상은 '광고성 정보'다

정보통신망법 제50조 제1항의 사전동의(opt-in) 규제 대상은 '영리목적 **광고성** 정보'다. 특정 회사의 특정 문제를 짚은 **1:1 개별 거래·제휴 제안은 광고성 정보로 단정되지 않는다** — KISA 안내서도 단순 거래 문의·개별 협의 제안을 광고성 정보와 구분한다. 따라서 국내 트랙은 무조건 차단이 아니라 **판정**이다.

## 판정표 — 광고성 정보 vs 1:1 개별 영업 제안

| 축 | 1:1 개별 영업 제안 (동의 불요 판단) | 광고성 정보 (opt-in 필요) |
|---|---|---|
| 작성 | 상대 회사명·직책·구체 접점이 본문에 실명으로 | 동일 문면 대량 살포 |
| 본질 | "만나서/통화로 협의하자"는 거래·제휴 제안 | 할인·이벤트·프로모션 소구, 상품 홍보 나열이 주 |
| 발신 | 실명·소속·연락처 + 연락 경위 명시 | 발신자·경위 불투명 |
| 종료 | 정중한 수신거부 문구 + 즉시 suppressions 반영 | 무료 수신거부 **수단**이 법정 의무 |
| 빈도 | 동일 인물 시퀀스 상한(기본 5회) 이내 | — |

**왼쪽 5조건 전부 충족 = 발송 가능(`legalBasis=SALES_PROPOSAL_1TO1`).** 하나라도 오른쪽으로 기울면 광고성 판정. **판정이 애매하면 발송 포기가 아니라 문면 수정이 기본 동작** — 실명 개인화를 넣고 홍보 나열을 거래 제안 한 줄로 바꿔서 왼쪽으로 옮긴다. 판정 절차·수정 지시는 [[send-policy]] §1.

## 광고성으로 넘어가는 순간의 의무 (병기 — 이때는 전부 필수)

광고성 정보로 발송하려면 **사전동의(옵트인 리스트) 또는 거래관계 예외**(아래) + 표시의무:
1. **제목 맨 앞 `(광고) `** — 리터럴 멱등 prepend. **변칙표기는 그 자체가 형사처벌**(제50조⑤ 1호): `(광/고)` `(광 고)` `(ad)` `[광고]` `（광고）`(전각) 전부 금지.
2. **본문 4항목**: 전송자 명칭 / 전화번호 / 사업장 주소 / **무료 원클릭 수신거부 안내+수단**. 하나라도 비면 발송 차단.
3. **야간(21시~익일 8시) 전송 제한** — 이메일은 법적 예외지만 업무시간 발송이 기본. 문자·카카오톡은 야간 별도 동의 필요로 더 엄격.
4. 푸터 최소 문안: `본 메일은 (광고)입니다. 수신을 원치 않으시면 [수신거부/Unsubscribe]를 눌러 주세요(무료). {회사명} | {전화번호} | {주소}` — 한/영 병기는 KISA 권고로서 안전측 기본 삽입.

### 거래관계 예외 (광고성 정보의 동의 대체 경로)
`legalBasis=TRANSACTION_6M` — 3조건 동시충족 필요: **직접 거래**(웹 크롤링 주소 배제, 명함 등 직접 교부는 인정) + **거래완료 180일 이내**(`dealClosedAt`) + **동종 재화**(`dealItem`). 공개출처 발굴 주소는 이 예외에 **안 든다.** 수신동의/거부/철회 의사표시에는 **14일 이내 처리결과 통지**(통지에 광고 삽입 금지).

## legalBasis 규칙 (normalize_contact.py·Code.gs koreanGate_와 일치)

```
NONE                → 국내 발송 차단 (판정·동의 어느 쪽도 없음 — 기본값)
SALES_PROPOSAL_1TO1 → 발송 가능. 단 개별 작성 근거(hookContext) 필수 — 없으면 차단
TRANSACTION_6M      → 발송 가능(광고 렌더링). dealClosedAt≤180일 + dealItem 필수 — 없으면 NONE 강등
BUSINESS_CARD_B2B   → 명함 직접 교부 등 직접 수집 — 발송 가능(광고 렌더링)
EXPLICIT_CONSENT    → 옵트인 — 발송 가능(광고 렌더링)
```
어느 경로든 발신자 명칭·전화·주소(config `SENDER_NAME/PHONE/ADDRESS`) 미입력이면 국내 발송 차단.

## 렌더러 동작 (apps-script/coldmail/Code.gs — 코드 강제)

- **SALES_PROPOSAL_1TO1**: (광고) 표기 없음 — 광고성 정보가 아니라는 판정이므로 표기가 오히려 허위가 된다. 대신 푸터에 발신자 3항목 + 정중한 수신거부 링크를 붙인다(판정 조건 ③④의 코드 보증).
- **그 외 국내 발송(광고성 경로)**: (광고) 멱등 prepend + 본문 4항목 + 무료 수신거부를 **자동 강제 삽입** — 사용자·Claude가 못 끈다.
- 전 트랙 공통: List-Unsubscribe / List-Unsubscribe-Post(RFC 8058 one-click) 헤더, 수신거부 토큰은 HMAC(원문 미보관·위조 불가). 발송은 Gmail Advanced Service `messages.send(raw)`(scope `gmail.send`).

## 절대 불변 2개 — 어떤 판정으로도 못 넘는다

1. **이메일 주소 자동 수집·추측 생성 금지** — 주소의 자동 생성·자동 수집은 형사처벌 대상(제50조⑤ 2·3호 → 제74조, 제50조의2). `{이름}@{도메인}` 조합·순열 생성 절대 금지. 허용은 **공개된 곳에 문자 그대로 있고 출처 URL이 남는 주소**(sourceUrl 기록)와 **정식 구독한 리드 DB**뿐.
2. **수신거부·명시적 거절 즉시 전면 중단** — 형태 불문, 절차 없이 즉시 suppression 등록 + 진행 중 시퀀스 취소. 재접촉 영구 금지.
