# help — 스킬 23종 전체 사용법 안내 (전체 개요 · §3 플로우 · §12 V1 훑기)

Sales Copilot은 영업전략을 길게 설명하는 도구가 아니라 **오늘 연락할 사람을 찾아 실제로 연락하는 자동 영업사원**이다(최종 포지셔닝). 이 스킬은 그 영업사원을 부리는 법을 알려준다 — 스킬 이름을 몰라도 된다, 상황만 말하면 된다. 그리고 help도 안내로 끝나지 않는다. **지금 상태를 보고 다음 행동 1개를 찍어주고 끝난다.**

## 실행 유형: [A] 자동 — 안내만 한다. 이 스킬은 아무것도 발송·수정하지 않는다. (승인 모드·권한 차이는 [[role]])

## 0. 준비 — 지금 상태를 보고 안내를 맞춘다
```bash
python3 "$CLAUDE_PLUGIN_ROOT/scripts/doctor.py"
python3 "$CLAUDE_PLUGIN_ROOT/scripts/crm.py" stats
```
- 설정이 비어 있으면 **[[setup]]부터** 권한다. 데이터가 있으면 "다음 행동 없는 리드 N건" 같은 **실제 숫자로** 진입점을 찍는다. 없는 숫자는 지어내지 않는다.

## 1. 스킬 지도 — 23종 (§3 전체 영업 플로우 순서)

| [[context]] | "회사 자료 학습해" | 영업 컨텍스트 8종 구축 — 가치제안·가격·사례·반론·금지고객·문체 |

## 2. 상황별 진입점 — 스킬 이름 몰라도 된다 (§3 플로우)
자연어로 부르면 알아서 해당 스킬로 들어간다. 자주 나오는 상황:
- **"명함 받았어"** → [[import-cards]] — 저장에서 끝나지 않고 다음 행동까지 만든다
- **"오늘 뭐하지"** → [[today]] — 매일 아침의 기본 진입점
- **"회신 왔어"** → [[classify-reply]] — 긍정이면 [[book-call]]로 바로 이어진다
- **"미팅 끝났어"** → [[after-meeting]] — 기회가 보이면 [[pipeline]]으로
- "연락할 사람이 없어" → [[icp]] → [[find-leads]] · 인맥부터 캐려면 [[relationships]]
- "가격·할인 얘기가 나왔어" → [[deal]] — 권한을 넘으면 상급자 상신
- "요즘 조용한 고객들" → [[revive]] · "우리가 잘하고 있나" → [[metrics]]

## 3. 처음이면 이 순서 (§12 V1 온보딩 경로)
1. **[[setup]]** — 직급·권한·승인 모드(§1 질문 11개). 이거 없이는 모든 발송이 DRAFT ONLY로 묶인다.
2. **[[context]]** — 회사 자료를 먹여 가치제안·가격·사례·반론을 만든다.
3. **[[import-cards]]** 또는 **[[find-leads]]** — 리드를 채운다.
4. **[[routine]]** — 매일 자동 루프(§7)를 건다. 이후엔 [[today]]만 보면 된다.

## 출력
```
📞 Sales Copilot — 뭐부터 할까
지금 상태: {doctor·stats 요약 — 예: 설정 완료 · 리드 34건 · 다음 행동 없는 리드 5건}
추천 진입점: {상태 기반 1개 — 예: 다음 행동 없는 리드 5건부터. [[today]] 돌릴까?}
(전체 지도는 위 표 · 스킬 이름 대신 상황을 말해도 됨)
```

## 원칙
- **없는 스킬·기능을 안내하지 않는다.** 위 23종이 전부다. 환각 금지 — 상태 숫자는 실측만, 근거 없으면 "확인 필요".
- 커넥터(Gmail·캘린더·CRM) 연결 시 그것을 우선 쓰고, 미연결이면 로컬 최소 CRM(`~/.sales-copilot/`)으로 동작한다 — 안내할 때 이 이중 경로를 구분해 말한다.
- **안내로 끝내지 않는다**(방구석 전략맨 금지) — 항상 지금 상태 기반 다음 행동 1개를 제안하고 끝낸다.
- 이 스킬 자체는 발송이 없다. 실제 대외 발송은 각 스킬의 발송 게이트(수신거부·중복 검사 → 사실 검사 → approval_mode)를 반드시 거친다.
