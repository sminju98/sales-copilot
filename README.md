# AI 영업맨 (Sales Copilot)

**명함·인맥·신규 리드를 실제 접촉과 미팅으로 바꾸는 Claude Code 영업 플러그인.**

설치하고 "설정하자"라고 치면 — 명함을 CRM에 정리하고, 오늘 연락할 사람을 뽑고, 콜드메일·문자 초안을 만들고, AI 전화까지 겁니다. 발송 전 수신거부·중복·법규를 자동으로 검사합니다.

## 뭘 해주나

| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 받은 명함이 서랍에 쌓여만 있다 | 사진 찍으면 연락처·회사·직함 자동 정리 + 감사 문자 초안까지 |
| 오늘 누구한테 연락할지 모르겠다 | 매일 아침 연락할 사람·후속·미팅을 우선순위로 뽑아줌 |
| 콜드메일 쓰기가 막막하다 | 상대 회사를 조사해서 개인화된 메일 초안, 발송·팔로업까지 자동 |
| 전화 영업할 시간이 없다 | 한국어 AI 전화로 노쇼 재예약·휴면 고객 재접촉 콜 |
| 답장이 없으면 그냥 끝난다 | 거절이 아니면 각도·채널 바꿔 다시 접촉 (메일→전화→소개) |
| 스팸으로 신고당할까 무섭다 | 발송 전 수신거부·중복·야간 시간·법규를 자동 검사 |
| 어디까지 얘기했는지 까먹는다 | 모든 대화·미팅을 CRM에 기록, 다음 할 일까지 정해둠 |

## 3가지 핵심 기능

### ① 명함 → CRM (사진만 찍으면)
명함 사진을 올리면 자동으로 연락처를 읽어 CRM에 저장하고, 어제 무슨 얘기를 했는지까지 정리해 감사 메시지 초안을 만듭니다. **"발송할까요?"** 만 확인하면 됩니다.

### ② 콜드메일 (조사부터 발송까지)
발굴 → 상대 회사 리서치 → 개인화된 메일 초안 → 발송 → 무응답 시 자동 팔로업. 스팸 신고를 안 당하게 발송 규정을 지키고, 첫 캠페인 전에 내 주소로 테스트를 한 번 보냅니다.

### ③ AI 전화 (vox.ai 연동)
한국어 AI가 대신 전화를 겁니다 — 미팅 리마인드, 노쇼 재예약, 휴면 고객 재접촉. 가격·계약 얘기가 나오면 사람에게 넘깁니다. (vox.ai는 별도 가입이 필요한 유료 서비스입니다.)

## 매일 어떻게 쓰나

1. 아침에 열면 **오늘 연락할 사람 큐**가 떠 있습니다
2. `오늘 누구한테 연락하지?` · `이 명함 정리해줘` · `이 회사에 콜드메일 써줘` 처럼 말 걸면 됩니다
3. 초안을 검토하고 승인하면 발송됩니다
4. 무응답은 알아서 다시 접촉 일정을 잡습니다

명령어 없이 **말로 시키면** 됩니다.

**명함관리 앱 따로 쓰고 있는데요?** 겹치지 않게 하나만 씁니다.

## 면책 (중요)

무료 오픈소스 도구입니다. **작업을 더 편하게 도와줄 뿐, 어떤 결과도 보증하지 않습니다.**

- ⚖️ **법률 자문이 아닙니다.** 발송 규정을 짚어주지만 최종 판단은 사용자·전문가 몫이며, 콜드메일·문자·전화로 생긴 **법적 책임(정보통신망법 등)은 사용자에게 있습니다.**
- 💸 **영업 성과를 보증하지 않습니다.** 계약·매출 결과에 책임지지 않습니다.
- 🔒 **계정 정지·데이터 손실에 책임지지 않습니다.** 발송의 최종 승인은 사용자가 하며, 계정·보안 사고 책임은 사용자에게 있습니다.
- 명함·연락처 등 **개인정보 처리 책임은 사용자에게 있습니다.** vox.ai·발송사 등 외부 유료 서비스의 비용·관리도 사용자 책임입니다.

- 🚫 **오남용 책임은 전적으로 사용자에게 있습니다.** 정상적·합법적 영업을 전제로 만들어졌고, 동의 없는 대량 발송(스팸)·이메일 주소 추측 생성·수신거부 무시·명단 불법 수집 같은 **불법 행위를 위한 사용을 금지합니다.** 도구는 이를 막도록(발송 게이트·수신거부 검사·테스트 발송 강제) 설계돼 있으나, 사용자가 우회·악용해 정보통신망법·개인정보보호법·플랫폼 약관 등을 위반하면 그로 인한 **제재·처벌·손해는 전적으로 사용자 책임**입니다.

**한 줄로: 판단과 실행은 사용자가 하고, 이 도구는 그 과정을 돕기만 합니다.**
